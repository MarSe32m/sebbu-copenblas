Manually creating release
1. Run Build OpenBLAS workflow for <version>
2. Download artifacts and drop them into COpenBLAS.artifactbundle
3. Update info.json version
4. Update version in README.md 
5. Push changes to main
6. Create a GitHub release

Using GitHub to automatically create release
1. Run the Release COpenBLAS workflow with separate package and OpenBLAS versions.
   For example, package version 0.3.35 can bundle OpenBLAS version 0.3.34.
   Currently though they are in sync and should be kept that way if at all possible.
